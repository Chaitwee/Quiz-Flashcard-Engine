# Problem Statement

## Problem
Students revising programming concepts often use scattered notes and have no simple way to test themselves, track progress or find weak topics.

## Scope
A command-line Python application where users can manage a question bank, take timed and scored multiple-choice quizzes, revise with flashcards, and view personal analytics and a leaderboard. Data is stored locally in plain text files. The project does not include a GUI, online accounts or networking.

## Target Users
First-year programming students and anyone who wants a simple offline tool for self-testing.

## High-Level Features
- Player names with separate score history
- Question bank: add, view, search, edit and delete, with categories and difficulty levels
- Quiz mode with category and difficulty filters, a 50-50 lifeline, a timer and a review of wrong answers
- Flashcard mode that repeats missed cards until they are known
- Analytics (average, best, worst, average time, per-category averages), a Top 5 leaderboard and clear-history option
- Input validation, error handling and logging
